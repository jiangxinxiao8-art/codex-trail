# 雨中曲 V4 · 轻松模式更新（原型 A）

一段可以自由行走、引导雨水和演奏材质的三维街道。本阶段先验证空间、动作、雨水与手感，尚未扩展七章剧情。

## Windows 打开

1. 关闭旧版启动窗口和网页，解压整个 ZIP 到一个新文件夹，保留旧版。
2. 双击 **启动雨中曲.cmd**，保持启动窗口开启。
3. 浏览器自动打开 `http://localhost:5173`。选摄像头或鼠标；摄像头需要 localhost 或 HTTPS。

仍需已安装 Node.js 22 或更新版本。脚本会尝试启用 fnm 中已有的 26/24/22；首次会安装依赖并校验随包手势模型。不要直接双击 index.html。

PowerShell 手动启动：

```powershell
npm.cmd install
npm.cmd start
```

正常体验不需要重新安装 Agent Skills，也不需要改图片配置。新原型不使用完整 AI 插画作为背景；旧原图、歌曲和完整 V3 均保留。

## 轻松玩，随时过关

默认开启轻松模式。左下角随时有 **一键过关**：直接完成本关、打开院门，不必完成手势挑战。完成弹窗会说明本原型到此结束，下一章尚在制作，并可选择继续自由听雨、再玩一次或打开旧版完整故事。

- **带我去下一步**：人物自动走到当前需要体验的物品附近；途中可停止带路。
- 雨棚和玻璃只需各两次引雨接触，标准模式为五次。已完成的发现不会因切换难度丢失。
- 悬滴放大至原来的 2.2 倍，轻松模式扩大对准范围并优先选择尚未触碰的雨滴。
- 指向雨滴附近会出现对准环，停留约 0.9 秒即可自动触碰，也可照常捏合、点击。
- 不想对准时，点 **轻触下一滴**；距离太远会先带路到灯下。也可按 Enter 触碰附近雨滴。
- “声音与操作”可关闭轻松模式、停留自动触碰，分别试听玻璃声和雨滴声。

玻璃使用独立的发声配额，悬滴旋律有独立音源；两者更突出，响起时背景音乐会短暂降低，再恢复你的音量设置。玻璃边缘和悬滴有局部亮起反馈。

## 这一段怎么玩

- 指向希望行走的位置，人物通过速度和加速度慢慢靠近。
- 走近铁皮雨棚，张掌左右/上下移动，引导连续落雨；鼠标按住并拖动等效。
- 听过金属后，向右走到玻璃附近。向街道里侧引雨，听不同的声音，观察下滑的水痕。两种材质可自由选择先后。
- 两种材质回应后，继续沿街走到右侧灯下，触碰悬滴，排列一段短旋律。
- 院门会打开。可以进入小院，也可以返回刚才的水洼；位置与状态不会因为镜头移动而重置。

水面可以踩过去，也可以在附近轻触。关闭摄像头小窗仍继续识别；设置里可切换鼠标、调音量、降低精度。顶部“换个视角”真实改变镜头的位置与观察角度。

| 方式 | 行走 | 引雨 | 触碰 |
|---|---|---|---|
| 摄像头 | 食指指向 | 张掌后移动掌心 | 捏合 |
| 鼠标 | 移动指针 | 按住并拖动 | 点击 |
| 键盘 | 方向键 / WASD | 空格＋方向键 | Enter，触碰附近对象 |

原型没有倒计时。默认只在对准雨滴时触发停留辅助；“一键过关”由你主动选择。院门打开即表示本关已完成，小院供自由探索，当前没有下一章入口。

## 保留的旧版

同一服务打开 `http://localhost:5173/?version=3`，或在声音设置里选择“打开保留的 V3 完整作品”。其原入口原样保存在 src/legacy-main.ts，六幕、飞行和室内旧实现继续可用。

V4 当前只有原型 A。完整的三维飞行原型 B、室内原型 C 和七章故事尚未实现，不能把 V3 的功能视作新三维系统已完成。

## 技术与美术

Three.js / @types/three 0.187.0；Vite、TypeScript、MediaPipe、Tone.js、GSAP 保留。建筑、主角、车辆、路灯、水面与雨滴独立使用同一米制坐标。静态几何和角色部件合批；自定义纸纹/排线、水面实时反射与世界落点波纹；没有整张背景图的平移缩放。

五首原始 MP3、模型与 WASM 均随包保留。材质音效为明确的实时合成声，不是实录采样。总线分开、声音冷却和每秒上限用于避免堆叠。原型不重新生成音乐。

自动画质只调整渲染像素倍率，保留核心碰撞、雨量、角色和空间。云端 SwiftShader 软件 WebGL 的帧率较低，实际报告见验证记录；不据此保证普通 Windows 电脑的帧率。建议 Chrome / Edge 开启硬件加速。
