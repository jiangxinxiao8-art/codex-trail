# 雨中曲

一座可以被亲手演奏的雨中城市。沿着雨声走过七章：听见城市、在小巷演奏、种伞导水、拨开倒影、让城市起舞、随风飞翔，最后回到窗边坐下。

## Windows 打开

1. 关闭旧版启动窗口和网页，把整个 ZIP 解压到一个新文件夹，保留旧版。
2. 进入 rain-in-rain-app，双击 **启动雨中曲.cmd**，保持窗口开启。
3. 浏览器会打开 `http://localhost:5173`。选择摄像头或鼠标，开始旅程。

需要 Node.js 22 或更新版本。你此前安装的 Node.js/fnm 可继续使用；启动脚本会尝试启用 fnm 的 26/24/22。首次启动自动安装依赖、校验随包模型。不要双击 index.html，也不需要再下载图片或歌曲。

PowerShell 手动启动（在本文件所在文件夹）：

```powershell
npm.cmd install
npm.cmd start
```

## 轻松地玩

默认开启轻松模式。每节都有 **带我过去** 和 **跳过本节**；跳过会直接进入下一段故事，不会把整部游戏当成已经结束。完成一节后出现 **继续前行**。飞行默认自动滑翔，可以选择沿河或钟楼路线，并用手或方向键微调。

悬滴比旧版更大。指向附近会自动对准，停留约一秒即可触碰；也能捏合、点击，或使用左下角的直接交互按钮。声音设置中可以关闭轻松模式、停留辅助，分别试听玻璃声和雨滴声。

游戏会在进入新章节时保存检查点。返回标题后选 **继续旅程**，沿用上次的鼠标/摄像头方式。重新开始会开启一段新的旅程。

| 输入 | 行走 | 引雨 / 飞行方向 | 触碰 |
|---|---|---|---|
| 摄像头 | 食指指向 | 张掌后移动掌心 | 捏合或停留 |
| 鼠标 | 移动指针 | 按住并拖动 | 点击或停留 |
| 键盘 | 方向键 / WASD | 空格＋方向键；飞行时直接用方向键 | Enter |

摄像头需要 localhost 或 HTTPS。预览小窗可独立收起，不影响识别；设置中可切换鼠标。画面只在本地处理。

## 沿途

1. **城市的噪音**：靠近雨棚与玻璃，向上引雨，让两种材质回应，再轻触灯下三滴雨。
2. **让雨唱一首歌**：走进小巷，自由组合风铃、玻璃和水面的音色。
3. **种下雨伞**：种下相连的两把伞。伞面真实阻挡落雨，接住的雨水汇成新的水洼；第三把伞可自由种下。
4. **水里的另一个世界**：靠近水洼，张掌或轻触拨动水面，镜头循着倒影进入低饱和的梦境。
5. **让城市起舞**：张掌引导不同方向的风，或轻触光点让城市自动演奏。雨伞摇摆、人物舞动、水面回应；准备好后随风起飞。
6. **飞过这座城市**：起跳、穿过屋顶、选择音乐风道，再朝远处的灯缓缓降落。光滴可以收集，不是强制通关条件。
7. **一盏灯，一场雨**：随意探索窗户、台灯、唱片机与茶杯。体验任意两件物品后，可以走到椅子前坐下，迎来片尾。结尾后还能留在房间听雨。

## 技术与验证

Three.js 0.187.0，Vite、TypeScript、MediaPipe、Tone.js 和 GSAP。全部游玩场景使用独立三维几何、共享世界坐标和程序化雨；原始插画仅保留作参考及旧版资源。五首原始 MP3 保持不变，章节之间自然交叉淡入淡出，互动音效独立混音。完整旧 V3 仍可通过 `?version=3` 打开。

```sh
npm test
npm run build
npm run test:v4
npm run test:v4:easy
npm run test:v4:camera
```

浏览器测试自动启动/关闭本地服务，Linux 默认 `/usr/bin/chromium`；可设置 CHROME_PATH，或用 BASE_URL 指向已有服务。V4_PRODUCTION=1 验证生产构建。
