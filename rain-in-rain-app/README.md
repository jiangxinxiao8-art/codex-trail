# 雨中曲 · Sing in the Rain — V3

电影式开场、单手手势、分层城市、地面舞蹈、透视飞翔和雨夜归家的互动艺术网页。

## Windows 开始体验

1. 解压整个项目文件夹，保留 `public`、`src`、`scripts` 等目录。
2. 安装 Node.js 22 或更新版本。若已经通过 fnm 安装了 26/24/22，启动脚本会尝试启用已有版本。
3. 双击 **`启动雨中曲.cmd`**。
4. 首次会安装依赖、校验附带模型。服务就绪后自动打开 `http://localhost:5173`。
5. 保持启动窗口开启。点击「开始体验」并允许摄像头，也可使用鼠标。

Windows 启动脚本经过路径/CRLF 静态检查，当前云环境无法执行 Windows 批处理；仍需在真实 Windows 电脑上验收。如果失败，窗口会保留错误供截图。

手动运行（PowerShell 使用 `npm.cmd`，避免 npm.ps1 执行策略问题）：

```powershell
npm.cmd install
npm.cmd start
```

常规开发与构建：

```sh
npm install
npm run dev
npm run build
npm run preview
```

`npm run start` / 双击启动文件固定打开 localhost；`npm run dev` 兼容原版开发命令。如果开发命令显示 Network 局域网地址，请在运行服务的电脑上使用 **Local** 地址，摄像头需要 localhost 或 HTTPS。不能双击 `index.html` 来运行 TypeScript 项目。

## 原版保留与升级内容

保留 Vite + TypeScript、MediaPipe Hand Landmarker、PixiJS、GSAP、Tone.js、标题首页、五首原始 MP3、互动音阶、鼠标备用模式、音量/暂停/重启。

升级基于原提交 `9ad0536`。改动前已保留 Git 备份分支 `backup/pre-v3-20261111` 与工作区外归档；历史音乐未改动。

- 约 26 秒自动片头：黑场淡入、景深层次、路灯亮起、独立车辆与转动车轮、真实距离驱动的走路、减速停步与抬头；可跳过。
- 三行署名准确为「游戏制作：蒋欣笑」「音乐生成：蒋欣笑」「美术制作：蒋欣笑」。使用本地 Long Cang 中文手写字体（OFL 授权）和软边遮罩显现，采用整行书写式揭示，不声称具有真实逐笔笔画数据。
- 摄像头预览复用 HandTracker 的同一个 video / MediaStream；镜像显示；隐藏预览不停止识别、不新增摄像头流。
- 掌心用于移动，指尖用于指向，捏合边缘确认；4% 死区、自适应低通、最大速度与加速度、摩擦减速。灵敏度系数为 .4，指尖不再直接设置人物位置。
- 世界坐标与平滑相机独立。天空、远景、中景、店面、地面、路灯/车/伞、角色、前景遮挡、雨和光效分层。脚与街道使用同一世界坐标。
- 连贯帽子、短发、翻领雨衣和无五官角色；独立部件、两段腿骨、按路程推进的支撑/摆动脚。具备呼吸、走、停、低头/抬头、转身、下蹲、跳跃、滑翔、落地、操作物件及坐下姿态。
- 六幕由有效交互推进，移除了原版 40–95 秒的强制展示等待。1–4 秒的生长/动作和较长的开场、飞翔/降落都具有实际内容并锁定必要输入。
- 飞行采用 **独立三维坐标与透视投影的 2.5D 方案**：建筑盒体各顶点投影、深度排序、循环城市、透视光环和迎面雨。没有加入 Three.js，也没有用一张背景缩放冒充立体飞行。
- 归家为程序重绘的独立室内对象：开门、暗灯变亮、伞从手边移到挂钩、旋转唱片、茶杯往返、膝部与坐姿过渡；最后在窗边休息。

## 操作

| 模式 | 移动 | 指向/确认 | 张掌 |
|---|---|---|---|
| 摄像头 | 掌心偏左/右，回中央减速 | 食指指尖指向，拇指/食指捏合 | 五指展开 |
| 鼠标 | 光标偏左/右，放中央减速 | 点击目标 | 按住空格 |

- 第一幕：沿街行走，并走近可交互路灯后点亮它。
- 第二幕：接住三颗不同位置的发光雨滴。
- 第三幕：在地面三处空地种伞。伞柄和伞面分别生长，最多保留五把。
- 第四幕：接近并触碰光池，镜头穿过水面后继续行走探索。
- 第五幕：张掌左右轻挥一段完整舞蹈；随后跳起。张掌维持飞行，掌心左右/上下改变方向与高度；穿过三环后完整降落。捏合可收集靠近的可见光滴。
- 第六幕：台灯、挂伞、唱片和茶杯可自由选择先后，完成四项后再坐下。最后拉远镜头、音乐淡出，窗外雨仍在下。

顶部有预览、音量、暂停、全屏。长时间停住会显示轻微手势示范与辅助按钮。设置中的「示范当前操作」提供可访问性辅助：实际走近物品并演示动作；飞行辅助平滑引向下一个环，不直接增加过环次数。

目标为普通观众自然探索约 4–7 分钟；没有倒计时、没有强制等满总时长。熟悉操作的自动化辅助路径会更快，不把测试用时等同于真人体验时长。

## 性能与真人验收

- Pixi 渲染上限 30 FPS，像素倍率封顶 1.5；手势约 15 FPS，动画独立运行。
- 云端 SwiftShader 软件 WebGL 测试中室内场景出现明显低帧率，已修正低帧率造成的时间拖慢并去掉不必要的全屏颜色滤镜。无法据此保证所有 Windows 电脑的帧率。
- Windows 建议使用支持硬件加速的 Chrome / Edge。若卡顿，可先缩小窗口或降低显示分辨率。
- 仍需真人验证：实际摄像头权限与占用、单手光照/遮挡、镜像方向、掌心中心区与手指捏合舒适度、飞行与光环容错、预览关闭后的真人识别、耳机音量与体验节奏。
- Windows 双击启动脚本尚需真实 Windows 环境确认；云端已验证 Node 启动器、构建和浏览器工作流。
