- 主原型请求 AI 场景图片的次数：0。
- 安装/实读指定 10 个技能，补读引擎材质配套技能，共 11 个。来源与内容哈希保存在 skills-lock.json。

浏览器通过实际方向键行走、真实鼠标按住拖动引雨、空格/方向键辅助引雨、点击三维悬滴，完成两种材质的发现和院门解锁。没有改状态来跳过条件。

- 听见水脚步，人物有速度限制与制动。
- 引雨改变雨滴速度，真实碰撞金属雨棚和垂直玻璃面；雨棚局部飞溅、玻璃下滑水痕及不同音色通过。
- 最终本轮引雨接触：金属 80 次、玻璃 18 次。
- 三个音符及独立院门转动通过；进入小院再返回起点积水。
- 相机绕转后建筑显示真实侧面；镜头位置改变，水洼世界坐标和状态保持一致。
- 几何数据检查 21216 个顶点，无 NaN/Infinity。
- 暂停/恢复、原生设置弹窗焦点约束、WebGL 上下文丢失及恢复均通过。
- 1280×720、2560×1080、1080×1920 实际渲染截图已检查；修正空间提示盖住主角的问题。

## 摄像头

最终生产版本使用真实官方 task/WASM、模拟摄像头视频验证：模型初始化和逐帧推理、单一视频流、仅一次 getUserMedia、镜像预览、关闭小窗后视频继续增长、无手输入稳定停住、模拟设备断开后的明确提示、切换鼠标后释放流。

损坏模型返回 HTML 时先校验再回退鼠标，不申请摄像头。截图 camera-preview.png 中为模拟视频，未录制用户摄像头。真人识别稳定性仍需本机验证。

## 声音测量

通过测试脚本在浏览器原生 AudioNode 主输出分支录制 124.3 秒真实游戏声音，再用 FFmpeg ebur128 测量；没有录制麦克风或用户摄像头，正常游戏代码也不含录音功能。

最终测量：**−25.0 LUFS**，响度范围 **6.2 LU**，真峰值 **−10.8 dBFS**，未削波。此为默认音量下的代表性流程测量，不等同于所有玩家操作、音量组合或真人听感验收。

已按第一次测量修正默认混音偏轻的问题。金属 FM、玻璃正弦、水面膜振和石板噪声在同一原有音效总线上，含声音冷却、普通撞击每秒 7 次限制（主动旋律另有 190 ms 冷却）及距离/左右声像。

## 性能与限制

本环境为 **SwiftShader 软件 WebGL**。最终流程平均约 **11.1 FPS**，自动精度降至像素倍率 **0.65**。这包含截图、视口变化和恢复检查，不是 Windows GPU 的稳定帧率基准；云端仍不流畅，不能宣称性能验收完成。

已将角色独立部件合批，主场景绘制次数从初期约 84 降至常见 25–32；保留 1000 雨滴、固定物理更新、人物动作和真实空间。纸纹从昂贵的逐像素散列改为小数据纹理；反射 512×256 限频；自动画质仅降低非核心像素开销。最终采样约 2860 个渲染三角形。真实 Windows 硬件加速和摄像头负载仍需测试。

本阶段没有实现新的三维飞行 B、三维室内 C 或七章重构；V3 旧功能仅作为保留入口。Windows 批处理只做静态路径/CRLF 检查，未在 Windows 执行。
