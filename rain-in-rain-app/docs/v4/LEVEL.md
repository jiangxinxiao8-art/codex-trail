# 原型 A 的空间与节奏

起点（x=-13）→ 可回访积水 → 雨棚（x=-8）↔ 玻璃（x=0）→ 悬滴（x=8.4–11.2）→ 小院（x=15.5,z=-3.6）。

主街是双向的；雨棚与玻璃无固定顺序。两种材质的引雨接触均被听见后，悬滴变亮。发现三个不同音符后院门打开。小院通过原门返回；没有单向坠落或钥匙在自己门后的死锁。

- 教：起点水面与脚步，让观众理解物体有真实位置。
- 发展：在雨棚停下引雨，看见连续改变的落点。
- 变化：向纵深引雨，玻璃与金属的声学/视觉反馈不同。
- 缓冲：走向右侧路灯，保留一段安静移动。
- 小高潮：自由排列旋律，街灯下的门回应。
- 释放：进入小院或回头再听。完成后仍可自由演奏。

实际移动参数来自 WorldModel：最大 1.4 m/s，加速度 3.4 m/s²；最短相邻目标距离约 5 m。目标不能只按屏幕坐标判定；触水距离 3.2 m，悬滴触碰范围轻松模式 6.5 m / 标准模式 3.5 m，对准使用屏幕距离并核验世界距离与可见性。键盘 Enter 可触碰附近对象。

自动化验收通过实际输入沿路完成引雨、物件反馈、进入小院、返回旧水洼；没有直接改探索状态。最终仍需观众反馈：是否能找到玻璃的引雨方向，声音差异是否易听见，人物停止和镜头跟随是否舒服。

## 轻松模式增量

默认两次引雨接触即发现材质；可切回标准五次。带路遵守原移动加速度，不瞬移；小院路线先沿街再转入院门。左下角显示两种材质和三滴雨的进度，可随时主动一键完成。完成弹窗明确此原型没有后续章节，消除“门后还有下一关”的误导。

雨滴显示尺寸放大 2.2 倍，屏幕容差 64–108 CSS px，按视口缩放；标准模式 24 px。优先未收集雨滴，避免反复捏到同一滴。对准出现圆环，默认 0.9 秒停留自动触碰；丢失目标立即清零。仍支持捏合、鼠标点击、Enter，并提供“轻触下一滴”按钮。
