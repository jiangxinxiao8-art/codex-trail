## 性能与限制

云端使用 SwiftShader 软件 WebGL，完整流程平均约 13.7 FPS，不能当作 Windows GPU 帧率承诺。自动画质会降低像素倍率，保留雨水碰撞、动作与空间。真实 Windows GPU、摄像头光照与手势舒适度仍需本机确认。Windows .cmd 仅做静态与 CRLF 检查，没有在 Windows 上执行。

美术为简化的程序化手绘三维模型。雨水使用可信的简化碰撞和导流，不是复杂流体。七章与结局已经连接；原型历史证据保留在 docs/v4，当前入口不会出现“未制作下一章”或“你没有卡关”的开发说明。
